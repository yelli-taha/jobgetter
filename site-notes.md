# Site notes: how to get to each company's job list

Read the company's section BEFORE opening its careers page. Update it after every visit, so the next run
goes straight to the right list. General know-how for every kind of careers site is in docs/website-playbook.md.

Format per company:

## <Company>
- Careers page: <url>
- Job system: <Workday / SuccessFactors / Greenhouse / own site / ...>
- Filtered list: <URL that opens the list already filtered to your area (and remote), or "filters don't change the URL">
- How to filter: <which filter / dropdown / search box, exact values to pick>
- Confirm location: <how each posting shows its location>
- Unusual: <cookie banner, slow loading, separate apply login, ...>
- Last sweep: <date> · <N jobs on the filtered list> · <what was added>
