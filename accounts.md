# Job-site accounts

Sites where you already have an account. Claude reads this before each run to tell you whether a site needs
"Sign in" or "Create a new account". Never write passwords here: they live in Chrome's password manager.
Key = the short site key Claude uses (also in data/sites.json). Sign-in method: Password or Google.
